# Security policy

Sims3Online is experimental software. Use it only on systems and networks you trust.

## Important limitations

The client/server protocol currently has no authentication or encryption. A server should not be
exposed to the public internet or to untrusted clients. Local game-controller interfaces are for
development and must remain local.

The project is not a supported player release. Do not rely on it to protect game saves or personal
data from untrusted users.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions. Report them
privately through a
[GitHub Security Advisory](https://github.com/ObsidianNetwork/Sims3Online/security/advisories/new)
or email [security@obsidiannetwork.au](mailto:security@obsidiannetwork.au), which is monitored.

Include a description of the impact and enough information to reproduce the issue safely. Avoid
including game files, saves, credentials, or personal data in a report.
